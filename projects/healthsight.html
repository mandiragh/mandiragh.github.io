Overview

Making healthcare data easier to explore

HealthSight is an agentic healthcare analytics application built during Patchamomma 2026. It enables users to explore CMS Medicare data using natural-language questions and receive structured, data-driven results.

Problem

Healthcare analytics often requires technical expertise

Large healthcare datasets can be difficult for non-technical users to explore because answering analytical questions often requires SQL and knowledge of complex data structures.

Solution

Natural language to healthcare insights

HealthSight provides a self-service analytics experience where users can ask questions in plain language and use AI-assisted workflows to retrieve and interpret relevant Medicare data.

How It Works

From question to insight

01 · Ask

The user enters a healthcare analytics question in natural language.

02 · Analyze

The AI workflow interprets the request and connects it to the underlying healthcare data.

03 · Query

BigQuery processes the relevant CMS Medicare data required to answer the question.

04 · Explore

Results are returned through the application for easier analysis and decision support.

Architecture

Google Cloud analytics stack

HealthSight combines Gemini-powered AI capabilities with Google BigQuery for healthcare data analysis and Google Cloud infrastructure for application deployment.
